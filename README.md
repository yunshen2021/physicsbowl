# ⚡ PhysicsBowl Arena (PhysCode)

A LeetCode-style local web platform for high school students preparing for the **AAPT PhysicsBowl Competition** (Division 1 & Division 2).

## ✨ Key Features
- **LeetCode Split Arena**: Split-screen problem solving with KaTeX LaTeX math rendering, SVG physics diagrams, progressive hints, and step-by-step solutions.
- **45-Minute Timed Mock Exam Engine**: Simulate official AAPT PhysicsBowl competitions with countdown timers, 40-question palettes, review flags, and diagnostic scorecards.
- **Interactive AAPT Reference Sheet & Constants**: Instant slide-out drawer containing physical constants ($c, G, h, e, \epsilon_0, k_B$) and equations.
- **Free-Body Diagram (FBD) Scratchpad**: Interactive drawing whiteboard for sketching forces and working out derivations.
- **Practice Heatmap & Topic Mastery**: LeetCode-style daily streak calendar and topic radar charts.

## 🚀 Quick Start

```bash
# 1. Clone repository and navigate to directory
git clone <your-repo-url>
cd physicsbowl

# 2. Set up virtual environment & dependencies
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# 3. Run the application
python run.py
```

Open your browser at [http://127.0.0.1:8000](http://127.0.0.1:8000).
